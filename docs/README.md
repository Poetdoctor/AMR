# Source documents

`content-spec.md` refers to the team's two interview documents as **Doc A** and
**Doc B**. This is which is which.

| File | Referred to as | What it is |
| --- | --- | --- |
| [`doc-a-amr-beyond-the-diagnosis.pdf`](doc-a-amr-beyond-the-diagnosis.pdf) | Doc A | "AMR Beyond the Diagnosis" — the team's patient narrative, written for public use. Source for the Stories section and for Home's six beats. Contains the attributed quotes from Norma Washburn and Sunny Loo, and the works-cited entries reproduced on the Learn index. |
| [`doc-b-provider-interview-analysis.pdf`](doc-b-provider-interview-analysis.pdf) | Doc B | Synthesis of the provider interviews — Hancock, Lester, Blondel-Hill, Liu, Kooner, Mroz. Source for the four Learn articles. Internal working material, not written for publication. |
| [`content-spec.md`](content-spec.md) | — | Exact copy and content requirements per section. Authoritative for wording; `../CLAUDE.md` is authoritative for stack, build order and scope. |

These are kept in the repo because the site's copy is derived from them and it
should be possible to check any quote against its source. The repo is private;
Doc B in particular names clinicians alongside their attributed views and was
not written for publication, so it should not be moved into a public repo or
into `public/` without asking the people named in it.

One quote in Doc A is not attributed to a named person — the PICC line, from
someone with prior nursing experience. It is deliberately left out of the
Stories pages rather than assigned to either interviewee.
