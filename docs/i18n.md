# Languages

The site is published in English, with French live and Simplified Chinese,
Punjabi and Farsi planned. The language set is chosen for who actually lives
here: French as Canada's other official language, and the three largest
non-English language communities in Metro Vancouver.

This is a project about people not being heard. A version of it only readable
in English would be arguing against itself.

## How it fits together

| Where | What lives there |
| --- | --- |
| `src/lib/locales.ts` | The registry — which languages exist, their direction, and whether they are `ready` |
| `src/locales/en.ts` | Interface strings, and the `Dict` type every other language is checked against |
| `src/locales/<code>.ts` | One file per language |
| `src/lib/i18n.tsx` | The provider: loads a dictionary, sets `<html lang>` and `<html dir>` |
| `src/components/LocaleLink.tsx` | `Link`/`NavLink` that add the language prefix |
| `src/content/<collection>/<code>/` | Articles, stories and team entries, one folder per language |
| `src/locales/narrative/<code>.ts` | The Home narrative — titles, fragments, prose, quotes |
| `src/locales/questions/<code>.ts` | The visit-prep question bank |

English is served from the root (`/learn`), every other language from a prefix
(`/fr/learn`). English is not moved under `/en`: the site is already deployed
and linked to, and the symmetry is not worth breaking those links for.

**Import `Link` and `NavLink` from `@/components/LocaleLink`, never from
`react-router-dom`.** A link that forgets the prefix silently drops a reader
back into English halfway through their visit, and nothing about the page looks
wrong when it happens.

## Adding a string

Add it to `src/locales/en.ts`. Every other language then fails to compile until
it has the key, because each is declared `const fr: Dict`. There is deliberately
no runtime fallback to an English literal — a missing translation should stop
the build, not quietly render.

## Adding a language

1. Add it to `LOCALES` in `src/lib/locales.ts` with `ready: false`. It now has
   no routes and does not appear in the switcher, so the work can land in
   pieces without half-translating the live site.
2. Write `src/locales/<code>.ts`.
3. Translate the content collections (`src/content/<collection>/<code>/`),
   `src/locales/narrative/<code>.ts` and `src/locales/questions/<code>.ts`.
4. For a non-Latin script, subset a font — see below.
5. Flip `ready: true`. `npm run test:locales` and `npm run smoke` will now hold
   that language to the same standard as the others.

## Two things that are not string swaps

**Right-to-left.** Farsi sets `dir="rtl"` and the whole layout mirrors. The
stylesheet and components use logical properties (`ps-`, `me-`,
`border-inline-start`) rather than `pl-`, `mr-`, `border-left`, so this works
without a second set of classes. Keep it that way: a directional class is a bug
that only shows up in one language.

The Home narrative's 3D composition is the exception that still needs doing —
its reading card is pinned to one side and its word slots are hand-placed
opposite, so it needs mirroring explicitly rather than by CSS.

**Fonts in the 3D narrative.** The scroll narrative draws text with troika,
which ships a Latin-only default and renders *nothing* for a glyph it does not
have — no fallback, no box, just absence. Every language needs a font file
passed explicitly.

A full CJK font is 5–10 MB, which would be unshippable, except that the 3D
scenes only ever draw the beat words: 37 short phrases, about 40 unique
characters in English and on the order of 150 in any other script. Subset the
font to exactly the characters in that language's `beats.ts` words and it comes
to tens of kilobytes. Do not ship a full font.

## Translation workflow

Machine-drafted, human-reviewed. The draft is committed so a reviewer has
something to correct rather than a blank file, and every locale file carries a
header saying so. A reviewer edits the file directly — it is the source of
truth, not a cache of anything.

Content in `src/content/` is reviewed through Decap CMS at `/admin`, which puts
the English and the translation side by side.

**Verbatim quotes need a decision, not a default.** The quotes throughout the
site are real people's words. Translating one silently changes what somebody
said. Where a quote is translated it should be marked as a translation with the
original reachable — on this project especially, that is the whole point.

## When a translation is not ready

Pages render `<UntranslatedNotice />`, which says — in the reader's language —
that what follows is in English. A blank page hides work that exists; a silent
fallback leaves someone scrolling a page they cannot read with no explanation
and teaches them the switcher lied.

This also means the team can publish an English article the day it is written
instead of holding it until four translations are ready. **Every use of
`UntranslatedNotice` is a to-do.**

## Tests

- `npm run test:locales` — every ready language is complete, nothing blank, and
  nothing still holding the English string. That last one is what actually
  happens: a key that type-checks because someone pasted English in and never
  came back. Exemptions live in `SAME_IN_ANY_LANGUAGE` and must each carry a
  reason.
- `npm run smoke` — walks every route in every ready language at two viewports,
  and checks `lang`, `dir`, and that the medical disclaimer is present *in that
  language*. Longer translated text overflowing a narrow screen is the failure
  nobody on the team would otherwise see.

  It also compares each localised page against the English one and fails on any
  block of prose that is byte-identical. That is the only check that can see
  copy still living in a component: such a page renders perfectly in every
  language, because it renders the English. Citations and the Community section
  are excluded, with reasons, in `scripts/smoke.mjs`.

- `npm run test:content` — every language's entries are held to the same
  standard as English, and a translation whose filename matches no original is
  reported rather than silently ignored.


## How content translations work

A page asks for a language. If the entry exists in that language it is used; if
not, the English one is returned with `translated: false` and the page renders
`<UntranslatedNotice when={!entry.translated} />`. Nothing is ever blank, and
nobody is ever quietly handed English without being told.

Filenames are the slug and are shared across languages — `learn/en/foo.md` and
`learn/fr/foo.md` are one article, reachable at `/learn/foo` and `/fr/learn/foo`.
A translation whose filename does not match an English original can never be
reached, so `npm run test:content` fails on one.

**Two fields are never translated, and must stay that way.** A story's `name`
and `attribution` are always read from the English entry, and the CMS marks both
`i18n: duplicate` so they cannot be edited on a translation tab. Consent belongs
to the person, not to a language: without this, a stale translated file could
publish under a real name somebody has since withdrawn, or republish a story
withheld everywhere else. A withdrawal has to take effect in every language at
once or it is not a withdrawal.

Citations are not translated either. A reference is the work as published;
rewriting an author or a journal makes the source harder to find.

## Quotes

The quotes throughout the site are real people's sentences. Translating one
means the words on screen are not the words that were said, so the site says so:
a translated quote shows "Translated from English" and keeps the original one
click away, tagged `lang="en"` so a screen reader switches voice for it.

Two things a reviewer has to get right that an ordinary translation review would
not catch:

- **Pronouns.** Norma Washburn is she/her in the source; Sunny Loo is he/him.
  The first French draft made Sunny feminine in three places.
- **Grammatical gender where English has none.** The visit-prep sheet is filled
  in and spoken aloud by a patient of any gender, and French first-person
  agreement would assign them one — *suis-je soumise*, *serai-je testée*. Every
  question is phrased to avoid the agreement rather than defaulting to the
  masculine. If a rewrite reintroduces one, find another way to say it.

## The narrative's fragments

`beats.ts` is the only place the floating words exist. The 3D scenes read them
through `SceneWords`, the flat path and the reading card read them directly.
They used to be written out again inside `scenes3d.tsx`, and the French card
read "Pourquoi ceci ?" while the scene behind it still said "Why this?" — about
ten minutes after the translation landed.

Those words are drawn in hand-placed slots sized for English. French runs 15–20%
longer; other scripts differ more. Prefer the shorter of two good options, and
look at the beat afterwards.
